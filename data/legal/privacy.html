GPT-Image2 圖庫｜隱私權政策

更新日期：2026 年 9 月 8 日

GPT-Image2 圖庫由 Phil 維護，提供圖片案例與提示詞瀏覽、我的最愛及投稿功能。本政策適用於 gpt-image2.zero2codex.dev。

我們使用哪些資料

瀏覽公開案例不必登入。使用 Google 登入時，我們透過 Google 與 Supabase 取得帳號識別資訊、電子郵件地址，以及 Google 提供的基本個人資料（例如名稱與頭像），用於識別帳號、顯示登入狀態、同步收藏及管理投稿額度。我們不會取得你的 Google 密碼，也不要求讀取 Gmail 郵件、Google 雲端硬碟或聯絡人。

Email 登入開放時，電子郵件地址用於驗證帳號、寄送登入連結或重設密碼。登入驗證由 Supabase 處理；驗證郵件透過 ForwardHello 寄送。收藏紀錄、帳號識別碼與投稿額度紀錄用於提供跨裝置收藏及每帳號每天最多 5 筆投稿的限制。

投稿會公開哪些內容

投稿時填寫的暱稱、標題、提示詞、分類、風格、場景、來源連結與圖片，會在你同意公開後送至本專案的公開 GitHub Issue，供維護者審核；通過審核的內容可能刊登於網站與公開程式碼庫。登入用電子郵件不會自動放進公開投稿。請勿在投稿中填入你不希望公開的個人資料。

資料儲存與服務供應商

網站與投稿圖片由 Hetzner 主機提供服務；Supabase 處理帳號、驗證、收藏與額度資料；Google 提供 Google 登入；ForwardHello 處理驗證郵件；GitHub 儲存公開投稿與案例；Cloudflare 提供網域服務與 Turnstile 防機器人驗證。這些服務可能在台灣以外處理資料，並依各自的隱私權政策提供服務。

瀏覽器本機儲存空間會保存登入工作階段、語言及操作偏好；伺服器及防濫用服務可能處理 IP 位址、請求時間、瀏覽器資訊與錯誤紀錄，以維持服務及排除問題。網站若啟用 Google Analytics，會使用它了解頁面瀏覽與使用情況。

Google 使用者資料

Google 使用者資料僅用於上述使用者可見的功能，不出售、不用於個人化廣告，也不用於訓練通用 AI 模型。資料只在提供服務、安全維護或依法處理所必要的範圍內使用與分享。本服務對 Google API 所取得資訊的使用與轉移，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、查詢與刪除

帳號、收藏與投稿管理資料依提供功能及維護服務的需要保留。你可以取消收藏、登出，或聯絡維護者申請查詢、更正、刪除帳號及相關資料；我們會確認身分並依請求範圍處理。公開 GitHub 內容、他人的副本、搜尋引擎快取及版本紀錄可能仍保留，無法保證一併移除。
